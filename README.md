## 🚀 Live Demo & Hosting on GitHub Pages

Follow these easy steps to host this portfolio on GitHub Pages:

### Step 1: Create a GitHub Repository
1. Go to [GitHub](https://github.com) and create a new repository (e.g., `portfolio` or `<your-username>.github.io`).
2. Make sure the repository is **Public**.

### Step 2: Push the Files
In this directory (`e:\XPECT\Resume`), open your terminal/command prompt and run:

```bash
git push -u origin main
```

### Step 3: Enable GitHub Pages
1. Go to your repository on GitHub.
2. Click on **Settings** > **Pages** (in the left sidebar).
3. Under **Branch**, select `main` and root `/`, then click **Save**.
4. Within 1-2 minutes, your website will be live at:
   `https://<your-username>.github.io/<your-repo-name>/` (or `https://<your-username>.github.io/` if using the user page repo).
